# 开发需求文档 — 荧光检测平台

## 项目概述

一款运行在安卓手机上的荧光强度检测 PWA 应用。用户使用手机后置镜头拍摄经物镜聚焦的硫磺素 T (ThT) 荧光图像，手动选取荧光区域后，软件自动计算荧光强度。

## 目标用户

实验室研究人员，不需要编程背景，操作简单直观。

## 功能列表

### F1. 开始页
- 显示应用标题"荧光检测平台"
- 显示副标题"荧光强度检测"
- "开始检测"按钮 → 进入拍照页
- "查看历史记录"按钮 → 进入历史记录页
- 页面风格：简洁、淡蓝色背景

### F2. 拍照功能
- 调用手机后置摄像头（`facingMode: 'environment'`）
- 实时预览画面
- 点击拍照按钮捕获当前帧
- 拍照后自动跳转到选区域页
- 返回时释放摄像头资源

### F3. 荧光区域选择
- 显示刚拍摄的照片
- 用户用手指在图片上拖动，绘制矩形选框
- 选框为蓝色虚线，半透明填充
- 最小选区尺寸：20×20 像素
- 支持重新拖动（新拖动覆盖旧选区）
- "开始分析"按钮：未选区时禁用（灰色），选区后启用

### F4. 图像处理与分析
- 自动对选中区域进行图像预处理：
  1. 灰度转换
  2. 中值滤波去噪
  3. 对比度增强
  4. 背景扣除
- 计算两个指标：
  - 平均荧光强度（区域内像素平均值）
  - 总荧光密度（区域内像素值总和）
- 生成伪彩色图像（热力图风格）

### F5. 结果展示
- 双标签切换查看"原图"和"伪彩色图"
- 显示平均荧光强度和总荧光密度（单位：a.u.）
- 显示 ROI 尺寸和检测时间
- 预留阿尔兹海默症定量检测结果区域（灰色虚线框 + "待开发"文字）
- "保存记录并返回首页"按钮

### F6. 历史记录
- 列表展示所有历史检测记录，最新在前
- 每条记录显示：缩略图、日期时间、荧光强度值
- 点击记录可查看完整结果
- 支持单条删除（需确认）
- 支持清空全部记录（需二次确认）

### F7. 离线支持（PWA）
- 首次加载后缓存所有资源
- 断网环境下仍可正常使用全部功能
- 支持"添加到主屏幕"，以独立窗口运行

## 用户操作流程

```
打开应用
  │
  ▼
[开始页] ──点击"开始检测"──→ [拍照页] ──拍照──→ [选区域页]
  │                                                  │
  │                                          拖动选择荧光区域
  │                                                  │
  │                                           点击"开始分析"
  │                                                  │
  │                                                  ▼
  │                                            [结果页]
  │                                          查看荧光值+伪彩图
  │                                                  │
  │                                    点击"保存并返回首页"
  │                                                  │
  ▼                                                  ▼
[开始页] ←────────────────────────── 自动保存至历史记录
  │
  └──点击"查看历史记录"──→ [历史记录页]
                              │
                       点击某条记录
                              │
                              ▼
                         查看详情（含原图+结果）
```

## 非功能性需求

- 不上传任何数据，所有处理在手机本地完成
- 图片处理在 2 秒内完成（通过缩放到 1024px 保证）
- 界面适配手机竖屏，最小支持 360px 宽屏幕
- 中文字体，清晰易读
