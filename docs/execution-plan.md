  - [x] `applyPseudocolor()` — 应用伪彩色

### 验证标准
1. 用一张测试荧光图片，处理器输出灰度图正确（R=G=B）
2. 中值滤波后椒盐噪声消失，细节不模糊
3. 直方图拉伸后像素值分布覆盖 0-255 范围
4. 背景扣除后边缘区域接近 0
5. 伪彩色输出颜色与灰度值对应正确
