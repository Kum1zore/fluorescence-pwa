# 设计规范 — 荧光检测平台

## 色彩系统

### 主色调：淡蓝色系

| 色值 | 名称 | 用途 |
|------|------|------|
| `#E3F2FD` | 浅蓝背景 | 页面背景色 |
| `#BBDEFB` | 浅蓝 2 | 卡片背景、输入框背景 |
| `#90CAF9` | 中浅蓝 | 次要按钮边框、分隔线 |
| `#42A5F5` | 中蓝 | 主按钮背景、选中状态、选框颜色 |
| ``#1E88E5` | 深蓝 | 标题文字、强调色、顶部栏 |
| `#0D47A1` | 最深蓝 | 正文文字色 |

### 辅助色

| 色值 | 用途 |
|------|------|
| `#FFFFFF` | 卡片背景、按钮文字 |
| `#F5F5F5` | 页面底色（备选） |
| `#E53935` | 错误提示、删除按钮 |
| `#43A047` | 成功提示 |
| `#BDBDBD` | 灰色边框、禁用状态 |
| `#757575` | 次要文字 |

## 字体

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
             "PingFang SC", "Microsoft YaHei", "Helvetica Neue",
             sans-serif;
```

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 28px | 700 | 页面主标题（开始页） |
| H2 | 22px | 600 | 页面标题（顶部栏） |
| H3 | 18px | 600 | 区域标题、卡片标题 |
| Body | 16px | 400 | 正文、按钮文字 |
| Caption | 14px | 400 | 辅助信息、时间戳 |
| Small | 12px | 400 | 备注、标签 |

## 间距

| 层级 | 数值 | 用途 |
|------|------|------|
| xs | 4px | 紧密元素间距 |
| sm | 8px | 相关元素间距 |
| md | 16px | 标准边距、卡片内边距 |
| lg | 24px | 区块间距、页面边距 |
| xl | 32px | 大区块间距 |
| xxl | 48px | 页面顶部/底部留白 |

## 圆角

| 元素 | 圆角 |
|------|------|
| 主按钮 | 12px |
| 卡片 | 12px |
| 图片容器 | 8px |
| 历史记录行 | 8px |
| Toast 提示 | 8px |
| 选框（ROI） | 0px（直角矩形） |

## 阴影

```css
/* 卡片阴影 */
box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);

/* 按钮悬浮 */
box-shadow: 0 4px 12px rgba(30, 136, 229, 0.3);
```

## 组件样式规范

### 主按钮（Primary）
```
背景：#42A5F5
文字：#FFFFFF
字号：16px, 字重 600
圆角：12px
高度：48px
内边距：左右 24px
宽度：全宽（父容器内）
```

### 次按钮（Secondary）
```
背景：透明
边框：2px solid #42A5F5
文字：#42A5F5
其他同主按钮
```

### 禁用按钮
```
背景：#BDBDBD
文字：#FFFFFF
无边框
不可点击
```

### 统计卡片
```
背景：#FFFFFF
圆角：12px
阴影：0 2px 8px rgba(0,0,0,0.1)
内边距：16px
标题：14px, #757575
数值：24px, #0D47A1, 字重 700
单位：14px, #757575
```

### 顶部导航栏
```
背景：#1E88E5
文字：#FFFFFF, 18px, 字重 600
高度：56px
返回按钮：左上角，文字"← 返回"，白色
```

### Toast 提示
```
背景：rgba(0,0,0,0.8)
文字：#FFFFFF, 14px
位置：屏幕底部，距底部 24px
动画：从底部滑入，2-3秒后自动消失
```

### 加载遮罩
```
背景：rgba(255,255,255,0.9)
居中旋转动画图标 + "处理中..."文字
```
